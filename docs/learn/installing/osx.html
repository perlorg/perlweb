A good setup for Perl on macOS:

  • macOS Editors and Terminals
  • macOS comes with Perl already installed. Open Terminal.app (found in Applications -> Utilities) and run [% WRAPPER code_snippet %]perl -v[% END %] to see the version of Perl that's installed.

If you want a newer Perl, or to keep your Perl separate from the system...

  • The Perl that ships with macOS is older than the latest release. If you already use Homebrew, brew install perl is a quick way to get a newer system-wide Perl.
  • If you want multiple Perl versions side-by-side, or stronger isolation from system tools, install Perlbrew. It separates your installation from the system Perl, so upgrading macOS is much less likely to cause issues with your own Perl setup.

Installing CPAN modules

  • App-cpanminus provides the cpanm tool, which makes installing modules very simple to do. Install it by running: [% WRAPPER code_snippet %]cpan App::cpanminus[% END %]
