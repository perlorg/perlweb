A good setup for Perl on Unix/Linux based systems:

  • Most Linux distributions either include Perl or make it available through their package manager (apt, dnf, pacman, zypper, apk, etc.). Use your distribution's package manager to install or update Perl. Open a Terminal and run [% WRAPPER code_snippet %]perl -v[% END %] to see the installed version.

If you want a newer Perl, or to keep your Perl separate from the system...

  • If you want a newer Perl than your distribution provides, or you don't want your work affected by OS upgrades, install Perlbrew. It separates your installation from the system Perl, lets you run multiple versions side-by-side, and means upgrading your OS is much less likely to cause issues with your own Perl setup.

Installing CPAN modules

  • App-cpanminus provides the cpanm tool, which makes installing modules very simple to do. Install it by running: [% WRAPPER code_snippet %]cpan App::cpanminus[% END %]
